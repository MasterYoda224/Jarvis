Settings

Everything runs on this device. Nothing is sent to a server I control.

Press Diagnostics to check GPU, model and storage.
What this honestly can't do: it can't control your phone, home devices, or other apps; it can't browse the live web; and the on-device model is far weaker than a frontier AI — it will be confidently wrong sometimes. Numbers it reports come from the built-in calculator, not from guessing.

Commands & install

Commands run instantly — no model needed, even while the brain is loading.

Install on your phone

Android: open this file in Chrome → ⋮ menu → Add to Home screen / Install app.
iPhone: open in Safari → Share → Add to Home Screen. Voice and commands work fully; the AI model needs WebGPU, which iOS does not have yet, so chat is desktop/Android only.
Best experience: served over HTTPS it installs as a real PWA and runs offline.

Commands

How it gets smarter

Every answer it gives is stored locally with a score. Before each new question it retrieves the most relevant past answers and your corrections and puts them in the prompt — so it stops repeating mistakes and starts matching how you work. 👎 on a reply teaches it the right answer; 👍 promotes that answer in future retrieval.

Text mode (iPhone)

iPhones have no WebGPU, so the language model cannot run there. Instead of failing, JARVIS switches to text mode: it answers from corrections you taught it, built-in researched notes, and live instant facts — and voice in/out keeps working. Toggle it yourself in Settings → Text-only mode. Teach it with learn: … and text mode gets more useful.

Offline

Served over HTTPS (or localhost), a service worker caches the app shell — it opens with no network. Model weights are cached separately by the browser after the first download. On file:// the service worker is skipped; the page itself still works offline.

Model tools

The model can call the calculator itself: it emits [[tool: fleet 65 15]], the app runs it, then it answers with the real result — so it can't invent your numbers.
